### Attention三层结构设计
以MLA为例，由于模型差异（DSV2\DSV3\其他模型的MLA）、平台差异（CUDA、ROCm、XPU）、kernel实现不同（triton、cutlass、ascendc）、甚至阶段不同（prefill、decode、chunkprefill）到会导致MLAAttention实现的差异，。

**模型层通用入口 MLAAttention**
+ 模型测通过调用 attn_out = self.mla_attn(q, kv_c_normed, k_pe, ...)
+ MLAAttention中通过调用self.impl.forward_mha来运行具体实现

**后端能力声明和选择单元 FlashInferMLABackend**
如何确定的？ platform信息是懒加载的，后续直接用对应（如cuda.py）的get_attn_backend_cls方法，根据kvcache type、use_mla、GPU compute capability选择最高优先级的backend，并且会判断当前场景下是否有支持的backend，同样要是用户指定了，也会判断是否支持。同时通过`get_impl_cls() -> FlashInferMLAImpl`方法指定对应的具体实现
```python
class MLAAttention(nn.Module, AttentionLayerBase):
```
