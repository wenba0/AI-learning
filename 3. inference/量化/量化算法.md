Q0：什么是hessian矩阵？
+ Hessian 矩阵，广泛地说，就是一个多元函数的**二阶偏导数组成的矩阵**
+ 一阶导数：函数往哪个方向变化最快，也就是斜率、梯度。二阶导数：这个变化速度本身在怎么变化，也就是曲率。
+ Hessian 矩阵是多元函数的二阶导数矩阵，用来描述函数在某一点附近的曲率、变量之间的耦合关系，以及不同方向上的敏感程度。它是理解优化、误差传播、Newton 方法、模型压缩和量化算法的重要工具。

Q1：为什么可以通过hessian矩阵传递量化误差呢？
+ 线性层的输出是多个通道共同贡献的，只要输入通道之间存在相关性，其他权重的调整就可能产生相似的输出变化。
+ Hessian矩阵 $H = X^T X$ 描述了不同输入通道之间的相关性，可以通过其进行传递

Q2：如何通过hessian矩阵传递量化误差？
+ 逐通道/逐层进行量化
+ 对于权重的第i个通道，量化前权重-量化后权重得到量化误差：$e_i = w_i - q_i$
+ 更新后面第j个通道的权重：$w_j ← w_j - e_i * Hinv[i, j] / Hinv[i, i]$
